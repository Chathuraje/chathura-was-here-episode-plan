## Scope and boundaries

This package tests the documented concept-to-idea model with only C020, C032, and C084. It contains three source dossiers, exactly two unnumbered candidate ideas, and one complete-brief preview. It does not approve an explanation or idea, select a location, identify a participant, create an episode or group, assign an object, generate a screenplay, or implement application features.

Creative claims, source claims, editorial interpretations, unverified documentary possibilities, and verified evidence are labeled separately. `selected_location_id` remains `null`; chronology, release, group, object, and episode positions remain unassigned. Location choice remains exclusively Chathura’s.

## Cross-source findings

- Both C020 sources enumerate all seven common factors. Pradeepika gives substantially more commentary; Margaya is a compact account. Their emphases around mental life faculty differ and should not be collapsed into a claim of permanence.
- Both C032 sources preserve a threefold classification by mode of experiencing and a fivefold classification distinguishing bodily and mental pleasant/painful feeling. This is a classification of `වේදනා`, not a taxonomy of every emotion.
- Both C084 sources distinguish concepts/names from ultimate analysis, but their category presentations are not identical. The Pradeepika heading says eight concepts while the supplied text enumerates only seven. The absent eighth item remains unresolved.
- The Margaya extracts contain no title-page, author, edition, publication, or page markers. They can be cited as repository extracts only; no missing bibliographic details are inferred.

3. Which idea, if either, merits reality research? Approval here would authorize idea refinement only, not location selection or screenplay work.
4. Does the C020+C032 link in IDEA-P01-A remain subtle enough, or does it risk imposing an inward framework on the people filmed?
