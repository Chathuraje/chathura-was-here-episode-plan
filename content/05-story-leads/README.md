# Story Leads

Real-world story leads found by researching a question from the [research shortlist](../04-story-discovery/research-shortlist.md).

- One file per lead, named `<Lead ID> - <short plain description>.md`, for example `SL-SQ05-001 - ….md`.
- Use the [story-lead template](../04-story-discovery/story-lead-template.md). The explorer app's lead editor writes files in that format.
- Every new lead starts as `unverified`. A lead is not a story until it is verified, consent is documented and a human selection decision has been made.
- Research logs go here too: `research-log-SQxx-YYYY-MM-DD.md`.
